# 🎮 Breakout Game

A classic browser-based Breakout game built using HTML, CSS and JavaScript.

## Features
- Interactive paddle controls
- Ball physics and collision detection
- Brick-breaking mechanics
- Score tracking
- Browser-based gameplay

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Play Online
[Play Breakout Game]((https://ishanshekharr.github.io/breakout-game/)

## Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.
3. Start playing!
